# Project Context

## Project Overview
ReactPage is a highly customizable content editor framework built with React. It provides a flexible system for creating and managing content through a modular plugin architecture.

## Core Architecture
- Built on React 16.14+ with TypeScript
- Redux-based state management
- Material-UI component library
- DnD (drag-and-drop) functionality
- Modular plugin system

## Key Components
1. Editor Core
   - Cell-based content structure
   - Drag and drop functionality
   - Undo/redo support
   - Multi-language support
   - Plugin system

2. Plugin System
   - Content plugins (slate, image, video, etc.)
   - Layout plugins (background, spacer, etc.)
   - Migration system for version updates
   - Custom plugin support

3. State Management
   - Redux for global state
   - Context providers for options and rendering
   - Middleware support
   - Serialization/deserialization
